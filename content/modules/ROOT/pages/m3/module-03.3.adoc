== アクティビティ: ダッシュボードとメトリクスの確認
{m3}

{rhcl} は、Kuadrant アップストリームプロジェクトの https://github.com/Kuadrant/kuadrant-operator/tree/main/examples[(examples from kuadrant.io)^] フォルダで、インストールを監視するためのさまざまな開始点を提供します。これらのダッシュボードとアラートはすぐに使用でき、環境に合わせて簡単にカスタマイズできます。

NOTE: 画像が小さすぎる場合は、クリックしてフルスクリーンで表示してください。

== Grafana へのログイン

. https://grafana-route-monitoring.{ocp_cluster_openshift_cluster_ingress_domain}/login[こちら^] をクリックして Grafana ダッシュボードに移動してください
+
image:m3/grafana-openshift-login.png[width=60%]
. *Log in with OpenShift* ボタンをクリックし、プロンプトが表示されたら、ユーザー名 `admin` とパスワード `{ocp_cluster_openshift_cluster_admin_password}` でログインしてください。
+
image:m3/grafana-openshift-login-cred.png[width=60%]
. *Allow selected permissions* ボタンをクリックしてください
+
image:m3/grafana-allow-permissions.png[link=self, window=blank, width=100%] 


== ダッシュボードへのアクセス

. 左側のナビゲーションから、*Dashboards* メニューにアクセスしてください。
+
image::m3/grafana-dashboards-list.png[link=self, window=blank, width=100%]
. *monitoring* フォルダをクリックして、事前にロードされたダッシュボードを表示してください。
+
クリックしてフルスクリーンで画像を表示してください。
+
image::m3/grafana-monitoring-dashboards.png[link=self, window=blank, width=100%]

== ペルソナベースのダッシュボードの確認

. *App Developer Dashboard* リンクをクリックしてデータを表示してください。`echo-api` と `travel-agency` API の両方のメトリクスが表示されます。
+
image::m3/app-dashboard-no-data.png[link=self, window=blank, width=100%]
. このワークショップでは、`echo-api` にトラフィックを生成してみましょう。 *上部* のターミナルで次のコマンドを実行してください。ターミナルには 403 と 429 エラーの組み合わせが表示されます。
+
[source,sh,role="execute",subs=attributes+]
----
for i in {1..1000}; do curl -k -w "%{http_code}" https://echo.travels.{ocp_cluster_workshop_main_domain}; done
----
. Grafana ダッシュボードのタブに再度アクセスし、以下のスクリーンショットに示されているリフレッシュボタンをクリックしてください。
+
メトリクスが Grafana ダッシュボードに表示されるまで、数回リフレッシュする必要がある場合があります。
+
ダッシュボードのさまざまなセクションで、429 と 403 のリクエスト、および合計リクエストが利用可能であることに注意してください。
+
image::m3/app-dashboard-with-data.png[link=self, window=blank, width=100%] 

. 次に、ページの左上にある *Platform Engineer Dashboard* リンクをクリックしてください。 
.. Gateway、HTTPRoute、およびそのポリシーを表示します
+
image::m3/pe-dashboard-gw.png[link=self, window=blank, width=100%]
+
[CAUTION]
====
HTTPRoute のポリシーが表示されませんか？ kube-state-metrics Pod を再起動する必要があるかもしれません。

* 右上のターミナルで次のコマンドを実行して、メトリクスを少し促してください。
+
[source,sh,role="execute",subs=attributes+]
----
oc rollout restart deployment/kube-state-metrics-kuadrant -n monitoring
----
* ブラウザの右上にある image:m3/refresh.png[width=30px] ボタンを使用してダッシュボードをリフレッシュすると、ダッシュボードの世界がすべて正常になります。

====
.. 合計リクエスト、レイテンシ、CPU とメモリの使用状況の詳細を表示します
+
image::m3/pe-dashboard-requests.png[link=self, window=blank, width=100%]

. 最後に、ページの左上にある *Business User Dashboard* リンクをクリックしてください。このダッシュボードには、トラフィックサマリーや過去のリクエスト比較など、ビジネスユーザーにより関連性の高いデータが表示されます。
+
image::m3/biz-dashboard-with-data.png[link=self, window=blank, width=100%]
