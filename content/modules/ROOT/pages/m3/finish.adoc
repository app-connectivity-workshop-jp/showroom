== このモジュールの完了おめでとうございます！

おめでとうございます！{rhcl} を使用してトラフィック管理を簡素化し、セキュア化する方法を学習しました。

*{rhcl}* が、豊富な Policy API を通じて _north-south_[.red]^*^ トラフィックフローを管理およびセキュア化し、サードパーティアプリケーションからコアサービスへのアクセスをセキュア化する方法を確認しました。

このセットアップにより、{corp} はさらに多くのサービスエンドポイントを安全にアクセスできるようにオンボーディングする準備が整いました。このソリューションは、マルチクラスタセットアップにまたがるように拡張することもできます。
