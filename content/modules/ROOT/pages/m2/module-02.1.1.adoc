== Activity: Kiali で Service Mesh を確認する
{m2}

Kiali は {rhossm} で管理されている microservices を調査するための多数の方法を提供します。これにより、ユーザーは service アーキテクチャの健全性を迅速に評価できます。

このモジュールでは、リアルタイム metrics を確認するためのいくつかの方法を確認します。

== Traffic Graph を確認する

. http://kiali-istio-system.{ocp_cluster_openshift_cluster_ingress_domain}/console/graphpf/namespaces/?graphType=versionedApp&namespaces=travel-agency&duration=60&refresh=10000&layout=kiali-dagre&edges=trafficDistribution&animation=true[Kiali's Traffic Graph^, window="kiali"] をクリックして、`travel-agency` namespace の詳細を表示します。
+
簡単にアクセスできるように、このリンクにはいくつかのパラメータが事前設定されています。リフレッシュレートは `10s` に設定されており、Traffic Distribution と Traffic Animation (動的ビュー用) オプションがオンになっています。

. *Traffic Graph* は service の相互作用、リクエストレート、HTTP status code を表示します。このグラフは、問題がある可能性のある service を特定するのに役立ちます。この例では、すべてが緑色で健全です。
+
画像をクリックしてフルスクリーンで表示します。
+
image:m2/kiali-graph.png[link=self, window=blank, width=100%]
+
NOTE: Sidecar injection は少し前に有効化されたばかりなので、グラフに更新された metrics が表示されるまで 1、2 分かかる場合があります。

. Kiali console にズームインして、`travel-agency` の Traffic Graph をより見やすく表示できます。
+
NOTE: このトラフィックはどこから来ているのか疑問に思っていますか? workshop のセットアップの一部として、トラフィックシミュレータも OpenShift にデプロイされています (｡◕‿◕｡)

== Workloads を確認する

. Kiali Console から、 http://kiali-istio-system.{ocp_cluster_openshift_cluster_ingress_domain}/console/workloads?duration=60&refresh=10000&namespaces=travel-agency[Workloads^, window="kiali"] メニューに移動します。
+
image:m2/kiali-workloads-travel.png[link=self, window=blank, width=100%]

. `travels-v1` workload を選択して、利用可能な各種 metrics を確認します。

. *Overview tab* は、選択された workload の健全性ステータスやトラフィック metrics を含む高レベルの要約を提供します。これにより、workload が mesh 内でどのように動作し、相互作用しているかを迅速に評価できます。
+
画像をクリックしてフルスクリーンで表示します。
+
image:m2/kiali-workloads-overview.png[link=self, window=blank, width=100%]


=== Optional Activity: 詳細な metrics の確認

時間があれば、提供されている metrics をさらに確認できます。

.[underline]#クリックして表示: 詳細な metrics の確認#

[%collapsible]
====

. *Traffic tab* は、選択された workload のインバウンドおよびアウトバウンドトラフィックを可視化し、リアルタイムのリクエストレート、レスポンスコード、レイテンシを表示します。
+
image:m2/kiali-workloads-traffic.png[Traffic]

. *Inbound Metrics* は、選択された workload への受信トラフィックに関する詳細なテレメトリを表示し、リクエストレート、レスポンスタイム、エラーレートが含まれます。
+
image:m2/kiali-workloads-inbound.png[Inbound Metrics]

. *Logs*、*Outbound Metrics*、*Envoy*、*Services*、*Istio Config*、*Mesh* タブも自由に確認してください。

====

== まとめ

おめでとうございます! 自動 Sidecar injection を有効化し、アプリケーションを mesh にオンボードし、Kiali を使用して service トラフィックを可視化および分析しました。
