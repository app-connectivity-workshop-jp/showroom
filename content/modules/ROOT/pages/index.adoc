== ハイブリッドクラウド向けアプリケーション接続性の保護

image:intro/hybrid-cloud.png[width=50%]


ハイブリッドクラウド環境は、企業に柔軟性、スケーラビリティ、俊敏性を提供しますが、同時に重大な接続性とセキュリティの課題も導入します。組織は、オンプレミス、プライベートクラウド、パブリッククラウド全体で、システムとサービスが効果的、安全、かつシームレスに通信できることを確保する必要があります。

主要な課題には以下が含まれます：

* 断片化されたアプリケーション接続性
* 複数環境間での設定のドリフト
* アプリケーション通信に適用されるセキュリティの不足
* リソースの誤管理
* ハイブリッドインフラストラクチャ全体の可視性の欠如

== ワークショップの目的

このワークショップでは、企業がハイブリッドクラウドアプリケーション接続性を保護し管理するのに役立つ Red Hat の接続性ソリューションをご案内します。実際の企業シナリオを通じて、以下の方法を学びます：

* VPN や複雑なネットワーキングなしで、異なるプラットフォームやクラウド上で実行されているサービスを安全に接続する
* 組織内外の両方でサービスを安全に公開し、利用する
* アプリケーションコードを変更することなく、同じクラスター内でもサービス間通信を制限する認可ポリシーを適用する
* GitOps を通じて複数のクラスター間で一貫したセキュリティポリシーを実装し管理する
* セルフサービスのガードレールにより、開発者がアプリケーション接続性を独立して管理できるようにする

ハンズオン演習を通じて、*{rhcl}*、*{rhsi}*、*{rhossm}* を使用してこれらの課題に対処し、ハイブリッドクラウドインフラストラクチャのセキュリティと信頼性を向上させる実践的な経験を得ることができます。
