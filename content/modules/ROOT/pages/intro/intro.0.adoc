== このワークショップの背景

image:intro/travelzcorp.png[width=70%]

このワークショップでは、アプリケーションインフラストラクチャを近代化している架空のグローバル旅行サービス企業である *{corp}* のストーリーに従います。この変革の一環として、{corp} はアプリケーションのクラウドへの移行を開始しました。 


== アーキテクチャ概要
{corp} アプリケーションアーキテクチャのハイレベルビューを以下に示します。


image::intro/hl-arch.png[]

* {corp} の Web ポータルとコアサービスは OpenShift に移行およびデプロイされていますが、データベースは Red Hat Enterprise Linux (RHEL) に残っています。
* {corp} のコアサービスは `travel-agency` Namespace に存在します。
** `hotels`、`cars`、`flights`、`insurances` サービスは、データを取得するために `travel-db` に接続し、適用するオファーを `discounts` サービスから取得します
** `travels` サービスは、Web ポータルへの REST API として機能します

チームは現在、アプリケーション間で必要な接続性を確立するために取り組んでいます。

しかし、ハイブリッドクラウド環境特有のいくつかの課題に直面しています：

* *クラウドとオンプレミスシステム間の安全な接続性*: 移行期間中、一部の重要なデータベースはオンプレミスに残っています。{corp} は、機密データを公開することなく、新しいクラウドベースのサービスをオンプレミスのデータベースに安全に接続する必要があります。
* *分散環境における細かいアクセス制御*: 分散型マイクロサービスアーキテクチャにより、誰が何にアクセスでき、どのような条件下でアクセスできるかを制御することがますます複雑になっています。企業には、細かく制御されたポリシー駆動のサービス間アクセス制御が必要です。
* *サードパーティパートナーへの安全なアクセス*: コアサービスは、信頼できるサードパーティパートナーがアクセスできる必要があります。{corp} は、不正アクセスや悪用から保護しながら、これらのサービスを安全に公開する必要があります。

このワークショップを通じて、あなたは {corp} のプラットフォームエンジニア、そして時には開発者の役割を果たし、Red Hat の接続性ソリューションを使用してこれらの課題に取り組みます。

== ワークショップの Module


このワークショップは、{corp} の旅路をたどるガイド付きウォークスルーを提供する 3 つの論理セクションに分かれています

image::intro/modules.png[link=self, window=blank, width=100%]

* *Module 1*: *{rhsi}* が OpenShift 上のコアサービスとオンプレミスデータベース（RHEL 上）とのシームレスな通信を可能にし、オンプレミスとクラウド間のアプリケーション接続性を実現する方法を確認します。

* *Module 2*: *{rhossm}* を使用して、サービス間の細かいアクセス制御、_East-West_[.red]^*^ トラフィック管理、複雑なデプロイメント戦略、Observability を通じてマイクロサービスを管理する方法を学びます。

* *Module 3:* *{rhcl}* が豊富なポリシー API を通じて _North-South_[.red]^*^ トラフィックフローを管理および保護し、サードパーティパートナーからのコアサービスへの安全なアクセスを実現する方法を学びます。

TIP: [.red]^*^ アプリケーション接続性において、_East-West_ トラフィックは内部コンポーネント/マイクロサービス間のデータフローを指し、_North-South_ トラフィックは内部システムと外部クライアント間のデータフローを指します。

== ワークショップ環境

これは完全ガイド付きワークショップです。必要なリンク、認証情報、アクセスの詳細、設定はすべて、必要なときに必要な場所で提供されます。事前のセットアップは不要です (ツ)

* AWS にデプロイされた Single Node OpenShift (SNO) クラスターと Red Hat Enterprise Linux マシンで作業します。
* ワークショップのアクティビティは、OpenShift コンソールと右側の統合ターミナルを使用して実行されます。
* このワークショップが短時間で完了できるように、いくつかのコンポーネントが事前設定されています。これらの各コンポーネントについては、ワークショップを進めるにつれて説明されます。

----

You can copy the command with the clipboard icon on the right'
----
* 手順と右側のターミナルウィンドウの幅は、リサイズグラブハンドルで調整できます。
+
image:intro/grab-handles.png[link=self, window=blank, width=100%]
