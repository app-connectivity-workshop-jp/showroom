== アクティビティ: アクセス設定を完了する
{m1}

OpenShift で以前に作成した Access Token を思い出してください。通常のシナリオでは、このトークンを OpenShift から RHEL サーバーに直接ダウンロードして転送します。

ただし、この **ワークショップ環境** では（ローカルファイルシステムへのアクセスやダウンロード機能が制限されている可能性があるため）、クラスターに保存された Access Grant をトークンに変換し、RHEL サーバーに転送する簡単なスクリプトを使用します。クラスター Grant には、特定の有効期限内および限定された引き換え回数で証明書を取得するための Grant URL とシークレットコードが含まれています。

NOTE: このスクリプトは、このワークショップの便宜のためだけのものであり、本番環境で {rhsi} を使用する場合には必要ありません。

=== OpenShift から RHEL に安全なトークンを転送する

. *OpenShift ターミナル（上部のターミナル）* で、以下のスクリプトを実行して Grant をトークンに変換し、ファイルに保存します。
+
[source,sh,role="execute",subs=attributes+]
----
curl -s https://raw.githubusercontent.com/app-connectivity-workshop/scripts/refs/heads/main/m1/convert_grant_token.sh | bash > summit_token.yaml
----

. *OpenShift ターミナル（上部のターミナル）* で、以下のスクリプトを実行して、トークンファイル（前のステップのもの）を RHEL サーバーに転送します。
+
[source,sh,role="execute",subs=attributes+]
----
scp summit_token.yaml lab-user@{rhel_hostname}:/home/lab-user/.local/share/skupper/namespaces/default/input/resources/
----


.. *Are you sure you want to continue connecting (yes/no/fingerprint)?* というメッセージが表示されたら、*yes* と入力して Enter キーを押します
+
image:m1/execute-script.png[]
.. *Failed to add the host to the list of known hosts (/data/.ssh/known_hosts).* というメッセージは無視してください

.. プロンプトが表示されたら、RHEL パスワード `{rhel_ssh_password}` を入力します。
 
=== RHEL で Virtual Application Network を開始する

. トークンが RHEL サーバーに転送されたので、*RHEL ターミナル（下部のターミナル）* から以下のコマンドを実行して Virtual Application Network を開始します。
+
[source,sh,role="execute",subs=attributes+]
----
skupper system setup
----
+
[CAUTION]
====
.`bash: skupper: command not found` というエラーが発生している場合はクリックしてください
[%collapsible]
=====
RHEL サーバーからログアウトされた可能性があります。

. *下部のターミナル* を使用して、以下のコマンドで RHEL サーバーにログインします。
+
[source,sh,role="execute",subs=attributes+]
----
ssh -o ServerAliveInterval=60 \
    -o ServerAliveCountMax=60 lab-user@{rhel_hostname}
----
. `Are you sure you want to continue connecting (yes/no/fingerprint)?` というメッセージが表示されたら、`yes` と入力して Enter キーを押します

. *Failed to add the host to the list of known hosts (/data/.ssh/known_hosts).* というメッセージは無視してください

. プロンプトが表示されたら、パスワード `{rhel_ssh_password}` を入力し、*Enter* キーを押します。

=====

====
